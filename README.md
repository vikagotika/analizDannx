# morrow
Сайт кабинки для записи голосовых воспоминаний. Макет сделан в Figma, вёрстка выполнена на HTML и CSS.

## описание использования ии при создании сайта:

При вёрстке я использовала ИИ-ассистента (Claude) как помощника. Он объяснял, как работают свойства CSS, и подсказывал решения для отдельных задач. Структуру страницы, макет, подбор значений и итоговую сборку я делала сама.

С помощью ИИ были сделаны следующие части CSS:

**1. Закреплённое меню (шапка сайта)**
- `position: sticky` / `position: fixed` и `z-index`: меню остаётся наверху экрана при прокрутке страницы;
- расположение ссылок «о нас», «история», «каталог», «воркеры» поверх картинки с помощью `position: absolute` и `left` в процентах.

**2. Подвал (подписка и контакты)**
- размещение текстов поверх фоновой картинки через `position: absolute`, `left` и `top` (классы `.t1`–`.t9`);
- стили полей ввода (почта, телефон) и кнопки «подписаться».

**3. Каталог (тарифы)**
- расположение названий, цен и описаний поверх картинки с карточками через `position: absolute` и `display: flex` (классы `.t11`–`.t14`).

Значения отступов и координат (`left`, `top`, размеры шрифтов) я подгоняла вручную под макет из Figma.

## Что я изменяла и подгоняла сама

- Собрала структуру страницы в HTML: секции «о нас», «история», «каталог», «воркеры» и подвал.
- Перенесла дизайн из макета Figma: выбрала размеры, цвета и положение элементов.
- Подгоняла координаты (`left`, `top`) и размеры шрифтов у текстов на картинках, пока они не совпали с макетом.
- Подключила шрифты через `@font-face` и заменила шрифт сайта на Open Sans, как в макете.
- Исправила найденные ошибки: опечатки в классах, лишнюю кавычку, незакрытые теги.
- Создала репозиторий на GitHub, добавила README и сделала репозиторий публичным.

## Помощь ИИ с ошибками

Когда что-то в вёрстке не работало, я описывала проблему ИИ-ассистенту (Claude), и он помогал найти причину. Так были исправлены:

- элементы не двигались через `left` и `top`, потому что у них не было `position`;
- стили не применялись из-за опечатки в названии класса;
- тексты подвала сбивались, потому что одинаковые классы использовались в двух блоках;
- картинка не выравнивалась по центру;
- в HTML были лишняя кавычка и незакрытые теги.

После подсказок я вносила исправления в код сама.
